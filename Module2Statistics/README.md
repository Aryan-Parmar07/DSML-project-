# Module 2 – Statistics for Data Science

Welcome to Module 2! This module covers core probability and statistical concepts crucial for machine learning, feature engineering, and data analysis.

## 📚 Contents

### 💻 Project Notebooks (`project-notebooks/`)

| Notebook | Topic | Description |
| :--- | :--- | :--- |
| [Descriptive_Statistics_Hands_On_Colab.ipynb](project-notebooks/Descriptive_Statistics_Hands_On_Colab.ipynb) | Descriptive Statistics | Measures of central tendency (mean, median, mode), dispersion (variance, standard deviation, IQR), skewness, and kurtosis. |
| [Sampling_and_Central_Limit_Theorem.ipynb](project-notebooks/Sampling_and_Central_Limit_Theorem.ipynb) | Inferential Statistics & CLT | Demonstration of probability sampling methods and simulation of the Central Limit Theorem (CLT) across sample distributions. |
| [Statistics_Mini_project_salesData.ipynb](project-notebooks/Statistics_Mini_project_salesData.ipynb) | Applied Statistical Project | Real-world statistical analysis and hypothesis-driven insights on retail sales data. |

## 🚀 How to Run the Notebooks

### Option 1: Google Colab
1. Download the desired `.ipynb` file from `project-notebooks/`.
2. Open [Google Colab](https://colab.research.google.com/) and upload the notebook.
3. Run the cells step-by-step.

### Option 2: Local Environment
1. Install requirements:
   ```bash
   pip install pandas numpy scipy matplotlib seaborn jupyter
   ```
2. Launch with Jupyter Notebook or VS Code.
