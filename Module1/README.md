# Module 1 – Data Science & Exploratory Data Analysis (EDA)

Welcome to Module 1! This module focuses on essential Python data manipulation, visualization, and exploratory data analysis using **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**.

## 📚 Contents

### 💻 Project Notebooks (`project-notebooks/`)

| Notebook | Focus Area | Description |
| :--- | :--- | :--- |
| [Pandas.ipynb](project-notebooks/Pandas.ipynb) | Data Wrangling | Core Pandas operations: Series, DataFrames, indexing, filtering, and aggregation. |
| [EDAMatSea.ipynb](project-notebooks/EDAMatSea.ipynb) | Data Visualization | Exploratory data analysis with Matplotlib & Seaborn (distributions, trends, relationships). |
| [ZomatoBasedMiniProject.ipynb](project-notebooks/ZomatoBasedMiniProject.ipynb) | Applied EDA Mini-Project | End-to-end exploratory analysis on restaurant listing and dining data. |

### 📊 Datasets (`datasets/`)

| Dataset | Format | Description |
| :--- | :--- | :--- |
| [customer_seg.csv](datasets/customer_seg.csv) | CSV | Customer demographic and behavioral data for segmentation analysis. |
| [salary_dataset.csv](datasets/salary_dataset.csv) | CSV | Years of experience vs. salary data for regression and distribution analysis. |
| [zomato_eda_mini_project.csv](datasets/zomato_eda_mini_project.csv) | CSV | Restaurant attributes, ratings, cuisines, and cost information. |

## 🚀 How to Run the Notebooks

### Option 1: Google Colab
1. Download the target `.ipynb` notebook from the `project-notebooks/` folder.
2. Download the required dataset from the `datasets/` folder.
3. Open [Google Colab](https://colab.research.google.com/) and upload the notebook.
4. Upload the dataset into Colab's session storage (`/content/`).
5. Run the cells sequentially.

### Option 2: Local Environment
1. Ensure dependencies are installed:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
2. Open the notebook in VS Code or Jupyter Notebook.
