# Module 3 – Machine Learning Fundamentals

Welcome to Module 3! This module covers foundational machine learning algorithms implemented with Python and `scikit-learn`.

## 📚 Contents

### 💻 Project Notebooks (`project-notebooks/`)

| Notebook | Algorithm | Description |
| :--- | :--- | :--- |
| [Linear_Regression_Student_Marks.ipynb](project-notebooks/Linear_Regression_Student_Marks.ipynb) | Linear Regression | Predicts student marks based on study hours using `LinearRegression` from `sklearn`. |
| [Logistic_Regression_Student_Pass_Fail.ipynb](project-notebooks/Logistic_Regression_Student_Pass_Fail.ipynb) | Logistic Regression | Classifies student pass/fail outcome based on study hours using `LogisticRegression`. |

## 🚀 How to Run the Notebooks

### Option 1: Google Colab
1. Download the target `.ipynb` notebook from the `project-notebooks` folder.
2. Visit [Google Colab](https://colab.research.google.com/).
3. Click **Upload** and choose the downloaded file.
4. Run the notebook cells sequentially.

### Option 2: Local Jupyter / VS Code
1. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib scikit-learn jupyter
   ```
2. Open the notebook in VS Code or run:
   ```bash
   jupyter notebook project-notebooks/Linear_Regression_Student_Marks.ipynb
   ```
